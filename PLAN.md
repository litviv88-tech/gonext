# План реализации дневника туриста

Порядок действий по `PROJECT.md`.

## Шаг 1. Зафиксировать архитектуру

Описать экраны, модели данных и хранение:

- вкладки: «Куда сходить», «Заметки», «Карта»;
- типы `Place` и `Note`;
- локальное хранилище AsyncStorage;
- контексты темы и данных дневника.

## Шаг 2. Подключить зависимости и каркас навигации

- установить `react-native-maps`, AsyncStorage и `expo-location`;
- собрать корневой layout с `PaperProvider`;
- добавить нижние вкладки Expo Router.

## Шаг 3. Сделать светлую и тёмную тему

- переключатель в AppBar;
- темы React Native Paper MD3;
- сохранение выбора на устройстве.

## Шаг 4. Реализовать блокнот «Куда сходить»

- список мест;
- диалог создания и редактирования;
- удаление места;
- пустое состояние.

## Шаг 5. Реализовать экран «Заметки»

- список заметок;
- создание, правка и удаление текста.

## Шаг 6. Реализовать спутниковую карту

- `MapView` с `mapType="satellite"`;
- переключатель спутник / схема;
- метки мест;
- долгое нажатие добавляет место.

## Шаг 7. Проверить в Expo Go

- запустить `npx expo start`;
- открыть приложение по QR-коду на телефоне;
- проверить места, заметки, карту и темы.

## Шаг 8. Опубликовать на GitHub

- закоммитить изменения;
- отправить в репозиторий `https://github.com/litviv88-tech/gonext`.
