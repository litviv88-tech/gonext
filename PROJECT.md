# Дневник туриста (GoNext)

Мобильное приложение для туриста на **Expo Router + TypeScript + React Native Paper**. Запуск на телефоне через **Expo Go**.

## Цель

Помочь туристу планировать поездку: куда сходить, что записать и где это находится на карте.

## Функции

1. **Блокнот «Куда сходить»**
   - список мест, которые хочется посетить;
   - добавление, редактирование и удаление места;
   - название и короткий комментарий;
   - необязательные координаты для метки на карте.

2. **Заметки**
   - отдельный блокнот свободных записей о поездке;
   - заголовок и текст;
   - добавление, редактирование и удаление.

3. **Карта со спутниковым видом**
   - карта открывается в режиме спутника;
   - можно переключить схему / спутник;
   - метки мест из блокнота «Куда сходить»;
   - долгое нажатие по карте добавляет новое место.

4. **Светлая и тёмная тема**
   - переключение в шапке приложения;
   - выбранная тема сохраняется на устройстве.

## Технические требования

- Expo SDK 54, чтобы приложение открывалось в Expo Go.
- Локальное хранение данных (без сервера).
- Навигация по вкладкам: места, заметки, карта.
- Код на TypeScript.
- Репозиторий на GitHub.
